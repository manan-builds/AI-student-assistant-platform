# AI Student Assistant Platform

An intelligent Python-based application that helps students interact with their study material using NLP and Transformer models.

This system allows users to:
1)Upload PDF documents (notes, books, papers)
2)Get a short summary of the document
3)Ask questions from the content
4)Analyze the sentiment of the text

It uses modern NLP models from Hugging Face such as BERT/DistilBERT.

#Technologies Used:
Python  
PyTorch  
Hugging Face Transformers  
Gradio (Web Interface)  
pdfplumber (PDF text extraction)
